## Findings considered and rejected

Recorded so they aren't re-audited next run:

- **Raw-socket / non-HTTP egress bypass** — by-design residual risk, explicitly
  documented in `SECURITY.md` and `AGENTS.md` §12 as the Phase-0 live-validation
  gap. Not a code defect.
- **TLS-MITM off by default** — documented, intentional (prefer the L7 proxy).
- **Broker compromise = session secret compromise** — documented non-goal.
- **No kernel/VM isolation** — documented non-goal (delegated to Cloudflare
  Sandbox).
- **Agent replay guard `seqRef.last` is in-memory (resets on restart)** — real
  but low-severity: bounded by the 30s freshness window, and the attacker would
  need to resend a captured signed command within that window after a restart.
  Not worth a dedicated plan now; note it if agent persistence is ever added
  (`packages/agent/src/zeronessd.mjs:98`).
- **Host matching doesn't normalize trailing-dot/IDN** — `evil.com.` evades an
  exact deny rule, but only reachable behind a broad `*` allow that `lint()`
  already warns against; fail-closed otherwise. Low value; revisit if host
  normalization is touched (`packages/core/src/policy.ts:55-64`).
- **`WebhookGatekeeper` uses a static shared-secret header, not a body HMAC** —
  minor; the endpoint is operator-controlled. Consider an HMAC-over-body upgrade
  if webhook auth is hardened (`packages/gatekeeper/src/index.ts:110-117`).
